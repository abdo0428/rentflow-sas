# ملاحظات التعلم

| الموضوع | الدرس التطبيقي |
| --- | --- |
| SaaS | لكل شركة مساحة تشغيل وأدوار وبيانات مستقلة؛ اشتراكات SaaS والفوترة التجارية نطاق منفصل. |
| Multi-Tenancy | company_id وحده غير كافٍ: يلزم نطاق موحد للاستعلامات، وقيود علاقات داخل الشركة، وسياق صريح للمهام الخلفية. |
| Authorization | إخفاء الزر لتحسين الواجهة؛ القرار الأمني يُعاد في المسار وPolicy والخدمة عند الحاجة، مع استعلام مقيد. |
| Laravel Policies | افحص الصلاحية والشركة والوصول للسجل. اختبارات تغيير IDs والتحقق نيابة عن مستخدم آخر تكشف ثغرات لا يظهرها المسار الطبيعي. |
| Service Layer | استخدمها للمعاملات وتغييرات الحالة متعددة السجلات. CRUD البسيط لا يحتاج طبقات إضافية. |
| Lease lifecycle | التفعيل يقفل الوحدة أثناء فحص التداخل وتوليد الدفعات. الإنهاء يحافظ على التاريخ ويحرر الإشغال وفق العقود المتبقية. |
| Payments | استخدم أعمدة decimal وتواريخ استحقاق مستقلة عن وقت السداد. الأشهر القصيرة وحدود المدة وإعادة تنفيذ الأوامر تحتاج اختبارات. |
| Maintenance workflow | جدول انتقالات واضح يمنع القفز بين الحالات؛ التعيين يتطلب موظفًا من الشركة والحالات النهائية تبقى نهائية. |
| Notifications | إشعارات قاعدة البيانات كافية للتدريب. الرسائل تُترجم عند العرض، وتذكيرات الدفع تمنع التكرار بعلامات الإرسال. |
| Files | تحقق من النوع والحجم والأبعاد، وخزّن الملفات خارج public. نظّف الصورة إذا فشلت المعاملة وأعد authorization عند كل تنزيل. |
| PDF | ملخصات بسيطة بخط يدعم العربية أسهل في الصيانة. اختبر PDF فعليًا ولا تكتفِ باستجابة HTTP ناجحة. |
| Localization | تشمل الترجمة الأخطاء والفلاتر والإشعارات وصفحة انقطاع الاتصال؛ البيانات التي يكتبها المستخدم لا تُترجم تلقائيًا. |
| RTL | استخدم start/end وms/ps، واختبر الأيقونات والنوافذ والجداول على الهاتف. إضافة زر قد تكشف overflow لم يكن موجودًا. |
| PWA | قائمة سماح للأصول الثابتة أفضل من تخزين كل GET. الصفحات والملفات الحساسة تحتاج شبكة، ولا تُؤجَّل المعاملات المالية دون تصميم صريح. |
| Testing | اختبارات MySQL للقيود وسير العمل، ومتصفح فعلي للتفاعل وRTL والانقطاع. افصل قاعدة الاختبار عن Demo، وشغّل build قبل اختبارات المتصفح. |
| Performance | لا تُكرّر استعلام Policy لكل زر في كل صف مقروء من نطاق آمن. اختبر نمو عدد الاستعلامات مع نمو الصفوف، وحافظ على Policies عند تنفيذ العملية. |

هذه تجربة Portfolio مكتملة ضمن النطاق التدريبي. جاهزية الإنتاج تتطلب تشغيلًا ومراقبة ونسخًا احتياطية واختبارات حمل إلى جانب صحة الكود.
