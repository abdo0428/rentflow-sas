# PWA وHybrid Mode

تعمل الواجهات المتصلة بالخادم كتطبيق ويب قابل للتثبيت. عند انقطاع الاتصال تظهر صفحة عامة بالعربية/الإنجليزية، وتبقى البيانات الخاصة متاحة عند الاتصال وتسجيل الدخول فقط.

## البناء والتثبيت

- `npm run build` يبني Vite، ثم يشغّل `php artisan pwa:assets` لإنشاء manifest وoffline fallback وأيقونتي PNG بحجم 192 و512، ويولّد `public/sw.js` بقائمة الأصول وبصمة الإصدار.
- مصادر العامل: `resources/js/service-worker.js`؛ التسجيل وزر التثبيت: `resources/js/pwa.js`. التوليد في `vite.config.js` و`BuildPwaAssets`.
- استخدم HTTPS في بيئة التشغيل؛ localhost/127.0.0.1 صالحان للتطوير. العامل يُسجّل في build الإنتاجي، وليس Vite HMR.
- نقطة البداية `/dashboard`، والنطاق جذر الموقع. زر التثبيت يظهر عند إتاحة المتصفح للتثبيت؛ على iOS يمكن استخدام «مشاركة ← إضافة إلى الشاشة الرئيسية».
- الأيقونات الحالية placeholders متناسقة مع العلامة، ويمكن تعديل مولدها لاحقًا.

## حدود التخزين

- قائمة سماح محددة: ملفات Vite الناتجة، الأيقونات، manifest، و`offline.html` فقط.
- تُجلب الأصول دون credentials، وتُفحص حالة الاستجابة ونوعها قبل التخزين. تُزال إصدارات cache السابقة عند تفعيل العامل الجديد.
- صفحات تسجيل الدخول والملفات الشخصية والعقود والدفعات والإعلانات وطلبات الصيانة وصورها وPDF لا تدخل Cache Storage. طلبات التنقل تعتمد على الشبكة دون حفظ الاستجابة.
- لا توجد مزامنة خلفية أو طابور طلبات أو تخزين مالي في IndexedDB/localStorage. يُحفظ اختيار اللغة فقط في localStorage، ويُمنع إرسال النماذج أثناء الانقطاع.
- عند العودة إلى صفحة من ذاكرة تنقل المتصفح، يعاد تحميلها للتحقق من الجلسة. تتطلب التنزيلات authorization في كل طلب.

اختبارات المتصفح تتحقق من محتويات Cache Storage وتحمّل المستندات بعد المصادقة، ثم تقطع الاتصال وتتأكد من عدم ظهور البيانات المالية. مرجع: [MDN — استخدام Service Workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers).
