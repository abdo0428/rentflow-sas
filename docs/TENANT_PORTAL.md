# بوابة المستأجر

- Layout مستقل في `resources/views/layouts/tenant.blade.php`، بتصميم Mobile First وشريط تنقل سفلي وقائمة إضافية، مع AR/EN وRTL/LTR.
- `TenantDashboardService` يجمع الوحدة والعقد الساريين، أقرب دفعة مستقبلية غير مسددة، المتأخرات، آخر طلبات الصيانة والإعلانات.
- الوحدة الحالية تعتمد على عقد active بدأ ولم ينتهِ؛ عند تعدد العقود يُعرض أحدثها. صفحة «عقدي» تعرض آخر عقد محفوظ إذا لم يوجد عقد سارٍ.

| الصفحة | المسار |
| --- | --- |
| الرئيسية | `/dashboard` |
| وحدتي / عقدي | `/tenant/unit` / `/tenant/lease` |
| دفعاتي | `/payments` |
| الصيانة | `/maintenance` |
| الإعلانات / الوثائق | `/tenant/announcements` / `/tenant/documents` |
| الملف الشخصي | `/profile` |

## الحماية والملفات

- استُخدمت إجراءات المرحلة الثالثة للصيانة والدفعات. المستأجر يقرأ سجلاته فقط، ويمكنه إنشاء طلب صيانة لوحدته المؤجرة دون تعيين موظف أو تغيير الحالة إداريًا.
- إعلانات company/all تخص شركته؛ إعلانات building تخص مباني عقوده السارية فقط. لا تُعرض المسودات أو المنشورات المستقبلية.
- وثائق العقود والدفعات السابقة تبقى لصاحبها؛ وثائق الوحدة المشتركة تتطلب عقدًا ساريًا.
- صورة الصيانة اختيارية: JPG/PNG/WebP حتى 5 MB وأبعاد حتى 6000×6000. اضبط upload_max_filesize=5M وpost_max_size=8M أو أعلى في PHP ثم أعد تشغيل عملية الويب. تُخزن الصورة في القرص local الخاص، ويُسمح بتنزيلها لمن يستطيع عرض الطلب، بما فيه الموظف المعيّن.
- ملخص العقد: `GET /leases/{lease}/pdf`. الإيصال: `GET /payments/{payment}/receipt` للدفعات paid ذات تاريخ دفع فقط. يتطلب كلاهما المصادقة والصلاحية وعزل الشركة/المستأجر.
- PDF عبر **mPDF 8.3.1** مع دعم العربية وDejaVu Sans، دون تحميل خطوط أو صور خارجية. تتطلب البيئة PHP GD وmbstring. الملخص تدريبي ولا يستبدل اتفاقية موقعة.
- تُولّد المستندات عند الطلب دون نشرها في public. ملفات mPDF المؤقتة داخل `storage/app/private/pdf-temp`، والتنزيلات والصفحات الديناميكية تحمل `Cache-Control: private, no-store`.

## لوحات الإدارة

`DashboardService` يحصر بيانات الشركة حسب المستخدم، ويتيح لمدير النظام إجماليات جميع الشركات والمستخدمين. نسبة الإشغال = occupied / جميع الوحدات؛ إيجارات الشهر هي المبالغ المجدولة غير الملغاة؛ الإيرادات هي دفعات paid المستلمة خلال الشهر؛ المتأخرات هي المبالغ غير المسددة ذات تاريخ استحقاق سابق لليوم. عرض الصيانة والإجراءات السريعة يتبع الصلاحيات.

التحقق: `php artisan test --compact tests/Feature/TenantPortalTest.php` و`npx playwright test tests/Browser/tenant-portal.spec.js`.
